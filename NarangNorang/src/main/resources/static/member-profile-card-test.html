멤버 프로필 카드 CRUD 테스트

1. 인증 토큰 설정 (JWT)

2. 프로필 카드 생성 (POST /memberProfileCard/create)

3. 프로필 카드 조회/필터 (POST /memberProfileCard/filter)

* 주의: 원본 코드는 @GetMapping을 사용하지만, Fetch API에서 GET 요청에 Body를 담을 수 없습니다. 테스트를 위해 백엔드의 @GetMapping("/filter")를 @PostMapping("/filter")로 임시 변경한 후 테스트하시길 권장합니다.

4. 프로필 카드 수정 (PATCH /memberProfileCard/update)

5. 프로필 카드 삭제 (DELETE /memberProfileCard/{id})
