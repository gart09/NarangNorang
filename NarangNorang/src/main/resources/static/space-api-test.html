  3. 룸 내 태그 목록 조회
  

    
    이 룸에서 스페이스에 붙인 태그들을 중복 없이 전부 조회
    
  

  
  






  4. 스페이스 목록 조회
  

    
    
  

  

    
    비워두면 해당 룸의 전체 스페이스 조회, 값 입력 시 그 태그를 가진 스페이스만 조회
    
  

  
  






  5. 스페이스 상세 조회
  

    
    
  

  

    
    조회할 스페이스의 id — 목록 조회 결과에서 확인 가능
    
  

  
  






  6. 스페이스 수정
  

    
    
  

  

    
    
  

  

    
    비워두면 이름이 null로 덮어써질 수 있으니, 수정 안 할 값도 기존 값 그대로 입력 권장
    
  

  

    
    
  

  

    
    비워두면 태그를 수정하지 않음(요청에서 제외됨). 값을 넣으면 기존 태그를 전부 교체함
    
  

  

    
    
  

  
  






  7. 스페이스 삭제
  

    
    
  

  

    
    삭제하면 SpaceProfileCard, Tag, SpaceMember도 함께 삭제됨 (되돌릴 수 없음)
    
  

  
  









  8. 스페이스 신청 (멤버 본인이 신청)
  

    
    지금 로그인한 계정이 이 스페이스에 신청함. 스페이스가 속한 룸의 멤버여야 함(MemberProfileCard 필요)
    
  

  
  






  9. 스페이스 권유 (오너가 특정 유저를 권유)
  

    
    지금 로그인한 계정이 이 스페이스의 오너여야 함
    
  

  

    
    권유할 대상의 User id. 그 룸의 멤버여야 함
    
  

  
  






  10. 스페이스 기준 대기 목록 조회 (오너용)
  

    
    이 스페이스에 걸린 PENDING 상태의 신청/권유를 전부 조회. 지금 로그인한 계정이 오너여야 함
    
  

  
  






  11. 신청/권유 수락 · 거절
  

    
    대기 목록 조회 결과의 id 값. 그 요청을 처리(승인)할 권한이 있는 계정으로 로그인해서 호출해야 함
    
  

  
  
  






  12. 내가 받은 신청/권유 목록 조회
  지금 로그인한 계정에게 처리 권한이 있는(=받은), 대기 중인 모든 신청/권유를 스페이스 구분 없이 조회
  
  









  13. 스페이스 탈퇴
  

    
    
  

  

    
    지금 로그인한 계정이 이 스페이스에서 탈퇴함. 오너는 탈퇴 불가(먼저 오너 위임 필요)
    
  

  
  






  14. 스페이스 오너 위임
  

    
    
  

  

    
    지금 로그인한 계정이 이 스페이스의 현재 오너여야 함
    
  

  

    
    새 오너로 지정할 User id. 이 스페이스의 멤버여야 함
